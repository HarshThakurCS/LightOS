# LighOS

**LighOS** is an experimental operating system built from scratch, with development currently focused on its kernel.

The project aims to explore operating-system internals and low-level systems programming, including CPU architecture, memory management, interrupts, process management, and hardware interaction.

## Status

🚧 **Early Kernel Development**

LighOS is currently in active development, with the primary focus on building and understanding the kernel from the ground up.

## Goals

* Build an operating system kernel from scratch
* Learn low-level systems programming
* Understand CPU architecture and hardware interaction
* Implement memory management
* Implement interrupt handling
* Explore process and task management
* Develop a foundation for future user-space components

## Project Structure

The project is currently focused exclusively on the kernel. User-space programs, libraries, and other operating-system components may be added in the future.
